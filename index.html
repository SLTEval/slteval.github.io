Workshop Overview

Beyond Proxy Metrics: Rethinking Evaluation for Speech and Language Technologies

Speech and Language Technologies have come a long way, but that progress hasn't come evenly. English and a few well-resourced languages enjoy massive datasets, mature tokenization, models scaled to hundreds of billions of parameters, and decades-refined benchmarks. Most of the world's languages, including most Indian languages, get sparse data that is rarely and barely representative of real-world nuances resulting in undertrained models, and little to no dedicated evaluation infrastructure of their own. Existing benchmarks, where they exist, also fail to capture rich linguistic phenomena such as disfluencies, code-mixing, morphological richness, dialectal variation, pragmatics, and noisy or spontaneous input, narrowing evaluation into optimization over proxy metrics (e.g., WER, BLEU, ROUGE) rather than a meaningful assessment of understanding, generation quality, or interaction.

SLT-Eval aims to bridge this exact gap, starting with Indian languages, whose sheer diversity in syntax, morphology, origin, script, and grammar makes them an ideal testbed for evaluation frameworks built to extend well beyond. The workshop is organized by the Language Technologies Research Centre (LTRC), IIIT Hyderabad to bring researchers across ASR, MT, TTS, Speech Translation, LLMs, and multimodal systems together to build standardized, interpretable evaluation methodologies, benchmarks, datasets, and metrics, alongside dedicated shared tasks.

SLT-Eval's key research questions:
  • How can evaluation move beyond proxy metrics toward meaningful linguistic, perceptual, and real-world quality?
  • How can evaluation generalize across languages, dialects, domains, and resource conditions?
  • How can automatic metrics be validated against human judgments while accounting for robustness, fairness, and linguistic diversity?

Call for Papers

We invite original research papers, position papers, and system demonstrations addressing evaluation challenges across speech and language technologies, moving beyond conventional metrics such as WER, BLEU, and MOS. Submissions must follow the ACL formatting guidelines. Accepted papers will be presented at the workshop and included in the proceedings.

Topics of interest include (but are not limited to):

  • Evaluation methodologies for MT, NLG, LLMs, and multimodal systems
  • Evaluation of ASR, TTS, speech translation, and Speech LLMs
  • Benchmark and dataset design for low-resource and multilingual evaluation
  • Human vs. automatic evaluation methods
  • Cross-lingual and code-mixed evaluation
  • Bias, robustness, and interpretability in speech and NLP systems

Shared Tasks

SLT-Eval 2027 introduces benchmark-driven shared tasks to evaluate speech and language technologies in Indian contexts. Each track provides datasets, evaluation protocols, and leaderboards to enable fair and reproducible comparison.

Track 1: Indic Spoken Question Answering (SQA)

Spoken Question Answering (SQA) focuses on answering natural language questions delivered as audio. Participants build systems that take spoken questions as input and generate answers in the same language. This track introduces benchmark datasets for Indic languages (starting with Telugu) and evaluates systems using an LLM-as-Judge framework designed to capture the linguistic richness of Indian languages.

Task Setup
  • Input: Spoken question (audio)
  • Output: Natural language answer
  • Languages: Telugu (others TBA)
Evaluation
  • LLM-as-Judge evaluation framework
  • Factual correctness, fluency, completeness
  • Language appropriateness (code-switch handling)
Participation
  • Build SQA systems (end-to-end or cascaded)
  • Submit predictions on held-out test set
  • Submit system description paper (ACL format)

Track 2: Indic Speech-to-Speech Evaluation Metric Task

This track focuses on developing automatic evaluation metrics for direct speech-to-speech translation systems. Unlike generation-oriented tasks, participants build models that predict human quality judgments for translated speech. The benchmark targets Indic language pairs and provides train, dev, and test splits with human annotations across multiple quality dimensions, encouraging research on robust, human-aligned metric learning for multilingual and morphologically rich speech translation scenarios.

Task Setup
  • Input: Source speech + system-generated translated speech
  • Output: Predicted human quality scores
  • Language pairs: Telugu–English, Hindi–English, Telugu–Hindi
Evaluation Dimensions
  • Intelligibility (0.30)
  • Adequacy (0.40)
  • Naturalness (0.30)
Participation
  • Build metric models that predict human scores
  • Submit predictions on official held-out test set
  • One primary + optional contrastive submissions
  • Submit system description paper
Ranking
  • Correlation with human judgments on test set
  • Composite score: 0.30 · Intel. + 0.40 · Adeq. + 0.30 · Nat.
  • Unseen speakers, domains, and speaking styles in test set
