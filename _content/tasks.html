Track 1

Indic Spoken Question Answering

Answer spoken questions in the same language, starting with Telugu. Systems are evaluated with an LLM-as-Judge framework.

Task setup

  • Input: Spoken question (audio)
  • Output: Natural language answer
  • Languages: Telugu (others TBA)

Evaluation

  • Factual correctness, fluency, and completeness
  • Language appropriateness and code-switch handling

Participation

  • Build an end-to-end or cascaded SQA system
  • Submit predictions on the held-out test set
  • Submit a system description paper in ACL format
Track 2

Indic Speech-to-Speech Evaluation Metric Task

Build automatic metrics that predict human quality judgments for translated speech, across unseen speakers, domains, and speaking styles.

Task setup

  • Input: Source speech and system-generated translated speech
  • Output: Predicted human quality scores
  • Language pairs: Telugu–English, Hindi–English, Telugu–Hindi

Evaluation & ranking

  • Intelligibility (0.30), adequacy (0.40), naturalness (0.30)
  • Ranking by correlation with human judgments
  • Composite: 0.30 · Intel. + 0.40 · Adeq. + 0.30 · Nat.

Participation

  • Submit predictions on the official held-out test set
  • One primary and optional contrastive submissions
  • Submit a system description paper
